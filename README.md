# 每日清静 · Daily Qingjing

> 人能常清静，天地悉皆归。

一个深山灰调国风的单文件网页，每天打开，一句《太上老君说常清静经》。

## 在线访问

👉 [https://chengyi-mountain.github.io/daily-qingjing/](https://chengyi-mountain.github.io/daily-qingjing/)

手机、电脑都能打开。

## 功能

- 🌓 **白天/夜晚自动切换**：6:00–18:00 是宣纸米色，入夜后转为墨色深山，颜色缓缓过渡
- 📜 **36 句《清静经》全文**：按"当年第几天"自动轮换，包含原文及葛翁曰等完整段落
- ⏰ **实时时钟**：顶部显示日期和当前时分秒
- 📖 **手动翻页**：上一句 / 今日 / 下一句按钮，键盘左右方向键也能翻
- 🏠 **一键回到第一句**：从头开始诵读
- 🌫️ **流动雾气 + 诗句淡入**：背景双层雾气缓慢漂移
- 🔔 **木鱼音效**：翻页时轻响一声（Web Audio 合成，无外部音频文件）
- 🎵 **背景音乐**：右下角按钮控制，点击页面自动播放，循环播放
- 🌐 **白话翻译**：点"翻译"按钮右侧弹出当前句的白话译文
- 📖 **看全文**：全屏阅读《清静经》完整内容，可一键切换原文/白话
- 🔍 **字体大小调节**：全文阅读时可自由放大缩小字体
- 📱 **手机端适配**：小屏自动调整字号和间距
- - 30 句 → 36 句（全文补全）
