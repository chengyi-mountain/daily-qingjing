# 每日清静 · Daily Qingjing

> 人能常清静，天地悉皆归。

一个深山灰调国风的单文件网页，每天打开，一句《太上老君说常清静经》。

## 在线访问

👉 [https://chengyi-mountain.github.io/daily-qingjing/](https://chengyi-mountain.github.io/daily-qingjing/)

## 本地预览

双击 `index.html` 即可在浏览器中打开，无需任何依赖。

## 它是怎么工作的

- 纯 HTML + CSS + JavaScript，无框架、无构建、无依赖
- 内置 15 句《清静经》金句
- 按"当年第几天"自动轮换，保证同一天看到同一句
- 部署方式：GitHub Pages 一键开启
